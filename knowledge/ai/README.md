# AI

本领域维护可复用的人工智能知识，包括基础概念、机器学习、神经网络、语言模型，以及模型评估与应用方法。各专题分别维护自己的机制解释、来源和适用边界。

## 阅读边界

从基础专题开始建立概念，再进入需要独立阅读或验证的算法、数学和工程专题。本领域不维护具体产品的架构、账号配置、模型选型记录、排行榜或一次运行的结果；具体项目应在自己的事实源中引用这里的通用知识。

未来新增机器学习、深度学习、语言模型或应用专题时，在 AI 领域下建立同级专题入口。只有形成实际内容时才创建目录，不把所有后续知识持续追加到基础篇。
