# 语言模型

本专题从文字的数值表示进入语言模型，维护分词、向量表示、上下文计算和文本生成的通用机制。先理解数据怎样进入网络，再逐步阅读模型架构。

## 阅读顺序

1. [小神经网络与训练循环](../deep-learning/小神经网络与训练循环.md)：先理解前向传播、反向传播与参数更新。
2. [Token与Embedding入门](Token与Embedding入门.md)：用一句话、查表图和训练流程，理解文字怎样成为网络输入。

## 事实源与边界

Token 与输入向量的具体解释由内容文档维护；对应来源见 [证据包](../../../evidence/ai/language-models/token-embedding/manifest.json)。注意力、位置与 Transformer 结构形成实际内容后，再增加独立入口。本专题不维护具体产品的分词计费规则、模型配置或能力排行榜；RAG 与工具调用进入应用专题。
