# 机器学习

本专题从可手算的小模型进入监督学习，维护模型形式、损失、优化和评估之间的关系。先理解计算，再运行最小实验。

## 阅读顺序

1. [AI基础与知识地图](../foundations/AI基础与知识地图.md)：建立数据、参数、训练和评估的共同概念。
2. [线性回归与梯度下降](线性回归与梯度下降.md)：用三个数据点推导损失、梯度和一次参数更新，再比较学习率。
3. [线性回归的最优解与更新依据](线性回归的最优解与更新依据.md)：补充最优解、初始参数、平方展开求导和负梯度方向的数学依据。
4. [小神经网络与训练循环](../deep-learning/小神经网络与训练循环.md)：把同样的学习过程扩展到带非线性激活的多层模型。

## 事实源与边界

主篇维护线性回归训练流程和实验入口，补充篇解释最优解与更新公式的数学依据；对应来源由各篇的证据包维护。本专题不维护具体产品的预测效果或部署方案。分类、正则化及其他算法形成实际内容后，再增加独立入口。
