# 本体论入门与知识地图

计算本体明确一个领域有哪些概念、它们彼此有什么关系，以及这些关系具有怎样的含义。用形式语言表达后，不同系统可以共享这些定义，推理器也可以结合具体事实推出隐含结论。学校例子贯穿全文，人物、任职和授权规则均为教学假设。[Gruber 的本体定义](https://tomgruber.org/writing/definition-of-ontology.pdf) · [OWL 2 Primer 第 2 节](https://www.w3.org/TR/2012/REC-owl2-primer-20121211/#What_is_OWL_2.3F)

## 1 存在、类别与同一性

哲学本体论研究什么存在、事物有哪些基本类别，以及一个事物经历变化后如何保持同一性。计算本体借用其中的区分，围绕具体问题选择要表达的对象、类别、角色和关系。学校的课程平台需要区分一门课程和某学期的开课班次，因为助教任职与授权可能随班次变化。[Gruber 的本体定义](https://tomgruber.org/writing/definition-of-ontology.pdf)

| 要表达的内容 | 例子 |
| --- | --- |
| 个体 | 小林、《机器学习》这门课程、某学期的开课班次 |
| 类别 | 人、研究生、课程、开课班次 |
| 类别之间的包含 | 每个研究生都是学生 |
| 个体之间的关系 | 小林选修某个开课班次 |
| 数据属性 | 课程的学分、任职的开始日期 |

“小林属于研究生类别”和“研究生是学生的子类”分别描述个体归类与类别包含。两条一起成立时，就能推出“小林属于学生类别”。[OWL 2 Primer 第 4.1、4.2 节](https://www.w3.org/TR/2012/REC-owl2-primer-20121211/#Classes_and_Instances)

## 2 领域建模与角色变化

小林可以同时在 A 大学具有学生身份，并在《机器学习》的某个开课班次担任助教。需要保留历史时，可以分别表达这段学籍和这段助教任职，把任职人、课程班次与有效时间关联起来。小林毕业后，这段学籍结束，助教任职是否结束由任职事实和适用制度决定。

```text
小林
├── 学籍记录 → A 大学，已结束
└── 助教任职 → 《机器学习》某开课班次，仍有效
```

模型因此能区分“曾是 A 大学学生”“这段学籍现在有效”和“现在担任这个班次的助教”。如果系统只需要按当前身份归类，可以从带时间的记录中提取当前状态。设计时先列出系统应能回答的问题，再决定需要保留哪些区分。[Ontology Development 101 第 3 节](https://protege.stanford.edu/publications/ontology_development/ontology101-noy-mcguinness.html)

## 3 形式逻辑与公理

描述逻辑常把公理按用途分成三组。下表的关系示例针对同一时点的事实快照。[A Description Logic Primer 第 1 节](https://arxiv.org/pdf/1201.4089v3)

| 组成 | 表达什么 | 学校模型中的公理 |
| --- | --- | --- |
| **TBox** 概念公理 | 类别的包含、等价、互斥等 | 每段助教任职都是一段课程任职。 |
| **RBox** 关系公理 | 关系的包含、组合等 | “担任某班次的助教”是“参与该班次教学”的子关系。 |
| **ABox** 事实断言 | 个体属于什么类别、彼此有什么关系 | 小林正在担任《机器学习》某班次的助教。 |

结合表中的 RBox 和 ABox，可以推出小林参与该班次的教学。**蕴含**指结论在每个满足已有公理和事实的解释中都成立。类别包含和关系包含有方向。从“所有助教都参与教学”可以推断助教参与教学。要把某个参与教学的人归为助教，还需要额外依据。[A Description Logic Primer 第 1、4 节](https://arxiv.org/pdf/1201.4089v3) · [OWL 2 Direct Semantics 第 2.5 节](https://www.w3.org/TR/2012/REC-owl2-direct-semantics-20121211/)

## 4 规则推理与信息缺失

假设当前快照中，`班次A` 是《机器学习》的某个班次。系统已经确认小林是该班次的在任助教，并且班次 A 允许在任助教批改作业。将教学假设中的授权政策写成规则伪代码，就能逐步检查结论的来源。条件同时成立时才能应用相应规则。[SWRL 提案第 2.2、3 节](https://www.w3.org/submissions/2004/SUBM-SWRL-20040521/)

```text
F1  当前助教(小林, 班次A)
F2  允许助教批改(班次A)

R1  当前助教(x, c) ∧ 允许助教批改(c) → 有批改权限(x, c)
R2  有批改权限(x, c) → 可以查看待批改作业(x, c)

F1 + F2，经 R1 → 有批改权限(小林, 班次A)
该结论，经 R2  → 可以查看待批改作业(小林, 班次A)
```

在 R1 中，`x` 绑定到小林，两个条件里的 `c` 都绑定到班次 A。另一个班次的授权无法满足这个绑定。**前向推理**从已知事实出发，应用匹配的规则，再将得到的结论作为后续规则的输入。在这个有限的示例中，过程在无法得到新结论时停止。

如果政策要求助教具有本校有效学籍，授权规则就需要包含这一条件。只有在任职、班次授权和有效学籍都获得支持时，修改后的规则才会推出权限。毕业事实能证明某段学籍结束，当前是否另有有效学籍要结合相应记录判断。

OWL 采用开放世界假设。如果知识库既推不出小林担任《高等数学》的助教，也推不出他没有担任，这个事实就是未知的。对“小林担任这门课的助教”执行 SPARQL `ASK` 时，`false` 只表示查询模式在本次查询中无解。要断定小林没有担任助教，还需要依据支持这个否定结论。[OWL 2 Primer 第 2 节](https://www.w3.org/TR/2012/REC-owl2-primer-20121211/#What_is_OWL_2.3F) · [SPARQL 1.1 第 16.3 节](https://www.w3.org/TR/2013/REC-sparql11-query-20130321/#ask)

对实际权限的判断使用应用明确规定的授权政策。推理器也可以检查一致性，例如判断一组明确的类别互斥公理与具体归类能否同时成立。[OWL 2 Primer 第 4.3 节](https://www.w3.org/TR/2012/REC-owl2-primer-20121211/) · [OWL 2 Direct Semantics 第 2.5 节](https://www.w3.org/TR/2012/REC-owl2-direct-semantics-20121211/)

## 5 表示、查询与校验

| 工具或机制 | 职责 | 对应问题 |
| --- | --- | --- |
| RDF | 用主语、谓语和宾语表达可连接的事实 | 小林担任哪个班次的助教？ |
| RDFS、OWL | 描述类别和关系的语义，支持相应的蕴含 | 能否推出小林参与了这个班次的教学？ |
| SPARQL | 查询 RDF 图中的模式 | 这个班次有哪些在任助教？ |
| SHACL | 检查提供的 RDF 图是否符合指定形状和条件 | 这些助教任职记录是否填写了开始日期？ |

例如，在 OWL 中声明每段任职至少有一个开始日期，即使某段任职的日期没有写入数据，知识库仍可能存在一致的解释。SHACL 可以要求被检查的记录至少有一个相应的属性值，缺少它时就报告校验结果。两种机制分别回答逻辑解释和数据完整性的问题。[OWL 2 Primer 第 2、5.3 节](https://www.w3.org/TR/2012/REC-owl2-primer-20121211/) · [SPARQL 1.1 Query Language](https://www.w3.org/TR/2013/REC-sparql11-query-20130321/) · [SHACL 第 4.2.1 节](https://www.w3.org/TR/2017/REC-shacl-20170720/#MinCountConstraintComponent)

## 6 本体工程与 AI 应用

本体工程从明确用途和范围开始，随后检查能否复用已有本体，定义需要的类别、关系和公理，并用目标问题检验模型。学校可以把“谁在某时点担任某班次的助教”和“校外助教能否批改作业”写成验收问题。新增角色、合并教务与课程平台的数据或调整授权政策时，这些问题也能用来检查原有答案是否仍符合要求。[Ontology Development 101 第 3 节](https://protege.stanford.edu/publications/ontology_development/ontology101-noy-mcguinness.html)

正式的表示、查询和校验规范已经支持实际应用。Gene Ontology 使用标准化的概念和关系描述生物学知识，支持基因产物的统一注释与跨数据库知识整合。[Gene Ontology 概览](https://geneontology.org/docs/ontology-documentation/)

在一个结合语言模型与知识库的教学问答系统中，可以让语言模型把“为什么小林能批改作业”转换成查询，由推理器返回 R1、F1、F2 和结论，再由语言模型组织答案。这是一种系统设计，符号推理的结论依赖已核实的事实和规则。

大模型辅助构建本体仍是研究方向。CQ4OE 预印本在其基准和实验设置下比较了九个模型。模型识别需求中明确出现的术语，比构造正确的类别层级、关系和公理更可靠。该结果针对从能力问题生成本体的任务。能力问题是本体应能支持回答的问题。[CQ4OE v1，2026-09-22](https://arxiv.org/abs/2609.26029v1)

## 7 学习目录

| 学习章节 | 学到能回答的问题 |
| --- | --- |
| 1 存在、类别与同一性 | 哪些是事物的类别，哪些是情境中的角色？ |
| 2 领域建模 | 为什么要区分课程、开课班次与助教任职？ |
| 3 形式逻辑与公理 | “所有”“至少一个”“互斥”分别承诺了什么？如何区分 TBox、RBox 和 ABox？ |
| 4 自动推理 | 怎样推出隐含结论？怎样区分逻辑矛盾与信息不足？ |
| 5 机器可读的表示 | 怎样用 RDF、RDFS 和 OWL 表达领域知识？ |
| 6 查询与数据校验 | 怎样用 SPARQL 查询事实，用 SHACL 检查输入数据？ |
| 7 本体工程 | 怎样确定范围、复用已有定义、对齐不同系统并维护版本？ |
| 8 知识图谱与 AI 应用 | 怎样把共享语义与搜索、问答和大模型应用结合起来？ |

掌握角色与实体的区分、能手工执行一次规则匹配后，可以从学习目录第 3 章深入。已知一名授课教师参与教学，试着判断“所有助教都参与教学”和“所有参与教学的人都是助教”这两句中，哪一句会把这名教师归为助教。
