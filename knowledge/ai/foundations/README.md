# AI 基础

本专题面向第一次系统学习 AI 的读者，建立理解后续算法和应用所需的共同概念。阅读不要求先掌握微积分或安装开发环境。

## 阅读顺序

1. [AI基础与知识地图](AI基础与知识地图.md)：从概念关系进入学习机制，再了解神经网络和文本大模型，最后完成自测。
2. [基础篇证据包](../../../evidence/ai/foundations/ai-basics/manifest.json)：对应关键概念和机制的一手来源、固定文档源码与核对基线。

## 范围与后续入口

本专题解释概念和最小机制，不展开完整数学推导、训练工程、具体模型比较或产品使用教程。

接下来依次阅读 [线性回归与梯度下降](../machine-learning/线性回归与梯度下降.md) 与 [小神经网络与训练循环](../deep-learning/小神经网络与训练循环.md)，进入机器学习和深度学习专题。

Transformer 内部结构，以及 RAG 和工具调用，开始独立建设时分别进入语言模型和应用专题。本页负责连接这些入口，具体知识由对应事实源维护。
