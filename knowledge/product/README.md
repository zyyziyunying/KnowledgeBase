本领域维护可复用的产品知识，包括用户需求、价值判断与商业化机制。各专题分别维护概念、来源和适用边界。

## 阅读边界

先进入专题索引，再阅读对应内容文档及证据包。本领域不维护具体产品的方案、定价、运营指标、预算、实验计划或执行状态；具体项目应在自己的事实源中引用通用知识。

需求研究、产品体验等主题形成独立内容时，在本领域下建立同级专题，不将它们持续追加到商业化讲义。
