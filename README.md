# 个人知识库

这是一个长期维护的个人知识库。仓库只沉淀可复用的技术知识，并按知识领域组织；Android 是当前建设重点，但不是整个仓库的边界。

## 知识地图

| 领域 | 当前内容 | 入口 |
| --- | --- | --- |
| Android | Framework 基础、源码阅读与面试主干 | [Android](knowledge/android/README.md) |
| Flutter | 已预留 Framework、Engine、Embedding 与渲染知识边界 | [Flutter](knowledge/flutter/README.md) |

新增领域时，在 `knowledge/<domain>/` 下建立自己的索引，并在这里增加一个入口。不要把不同领域的内容堆进同一份总文档。

## 仓库边界

本仓库维护通用机制、源码入口、验证方法、适用版本和知识之间的关系。具体产品或项目的架构、硬件配置、代码现状、问题、计划与验证状态不在这里维护；未来需要组合知识库与具体项目时，应由独立项目引用本仓库，而不是把项目事实复制进来。

## 维护原则

- 根索引只负责导航；具体结论由最接近主题的文档维护。
- 内容优先采用“结论 → 机制 → 证据/源码入口 → 边界”的表达方式。
- 涉及版本差异时，注明 Android 版本、分支、设备或验证日期；不要把阶段性观察写成恒定事实。
- 外部资料优先链接官方或一手来源，并把个人推断与来源明确区分。
- 文档达到影响检索、审阅或独立维护的程度时再拆分；拆分后不在多个文件重复维护同一事实。

协作或自动化维护本仓库前，请先阅读 [AGENTS.md](AGENTS.md)。
